This entry explains an everyday thing in exactly two lines. The first line
makes a candle click for a 10-year-old through one vivid analogy: the flame
never burns the string — it melts a pool of wax, the string drinks that wax
up, and the fire feeds on the gas rising off the top. The second line gives
the honest accounting: it says what the straw mapping covers, and admits
what it leaves out — a gust can scatter the gas and starve the flame.

The text itself lives in `entry.txt`. The program in `main.ts` (Node 22,
standard library only) reads that file and writes it, byte for byte, to
`entry.txt` inside the directory named by `MAKEFUN_OUTPUT_DIR`.
